# 文本与混合来源接口扩展

基于主分支 `8fb29cc5687eab635dae9f18c8fc9493d5833a8c`，提取独立评测部署中的通用适配。
动机来自 ComindX 的 ScriptMem 文本资料与 ATM 图片/邮件资料；题库、答案、评分、调度、费用和
实验数据库不进入产品仓库。实现通过独立分支提出，未合并或部署到现有服务。

## 改动与原因

| 原限制 | 接口或行为变化 | 原因与兼容边界 |
| --- | --- | --- |
| 只有图片观察可进入助手证据链 | 默认空串 `source_text`、UTF-8正文索引、`read_source_text`、文本/混合规划与L1/L2证据 | 文本资料需要可追溯全文，不能转图或把生成摘要冒充原文；普通照片提示与流程保留 |
| 内容去重无法区分同字节的多个来源 | 可选外部来源ID、时间、地点、元数据；scope内身份幂等与409冲突 | 来源身份决定证据位置；同内容异ID独立，无ID继续旧哈希去重 |
| 同身份的并发首次导入可能竞争唯一索引 | 仓储只识别该唯一约束，返回胜出资产，由用例复核全部幂等字段 | 并发相同输入不应500，也不能吞掉无关数据库错误；不使已处理竞争污染外层事务 |
| 来源时间地点会被导入时间或观察值替代 | 保存原始字符串，来源时间优先EXIF，原始地点单列及索引 | 保留证据原义；不推断时区，当前明确拒绝有时区时间；旧带时区与新无时区记录不按时间归并或匹配时间窗，不把元数据伪装为视觉识别 |
| 同scope的另一回合结果集可绕过本轮检索流程 | 文本/混合回合校验当前结果集；工具再次校验scope、类型和可选发布清单 | 保证正文精读和图片复核使用实际取得的授权候选；旧照片流程保持 |
| 评测问答期间资料可能被HTTP修改 | 可选资料只读模式与来源发布清单 | 固定可见资料；默认关闭，保留会话/轨迹写入，不新增认证或快照服务 |
| 实际视觉字节和输出上限不易核实 | 可选标准编码/血缘与可配置视觉输出、思考、超时；Chat输出/步骤可配置 | 显式部署可追溯；未启用清单时原请求编码不变，输出默认2048、步骤默认8，思考默认省略 |
| 各仓储自行提交，无法把来源成功收据一起提交 | 同实例上下文共享SQLite事务、savepoint及rollback-only | 为调用方原子提交提供边界；原件、云请求和外部索引仍独立管理 |

公开输入 `StartTurnRequest.message` 字符上限从8000扩到131072，以保留完整问题和选项；
模型输入token预算由端点与部署执行层另行检查，字符数不等于token数。资产摘要、OpenAPI和
前端类型同步新增可选来源字段。`runtime_configuration` 同步输出实际预算与只读开关，不包含密钥。
上游Mac部署预设、0.85上下文压缩、安全余量、遥测及导入进度全部保留。

## 验证与限制

使用合成资料、临时SQLite、本地假HTTP模型验证原文/索引、混合检索、权限、元数据、并发幂等、
事务回滚、真实请求体参数、原图与派生图哈希、旧默认值及迁移回退。具体测试文件与契约见
[接口说明](../runbooks/comindx-benchmark-adaptation.md)。

本次不重启或改写现有服务，不重跑已停止的实验。真实模型、487QA及多设备发布回归未由这些
离线测试替代；本PR保持草稿，合入与发布前按仓库既有真实环境门禁验证。模型名称、云代理、
未知请求不重放、全量预算和评分均由外部执行层管理，不能从产品配置推断其已实现。

## 回退

优先回退代码并关闭新增可选配置。0014/0015只增加有默认值或可空的列及唯一索引，旧代码读取
自己的显式列，保留扩展列可避免丢失新增资料。部署升级前另存数据库、媒体和索引的完整副本。

需要恢复旧schema且新增字段尚未使用时，在离线副本运行：

```sh
python scripts/rollback_source_adaptation.py input.db schema-0013.db
```

脚本通过SQLite backup生成新文件，拒绝覆盖任何现存输出，不修改输入；验证没有新增正文或来源
元数据、没有后续迁移后，反向移除0014/0015并检查外键/完整性。已使用新字段则拒绝丢失数据，
应恢复升级前完整副本或保留扩展schema回退代码。不得把旧备份数据库与新派生索引拼接；索引应
从选定权威数据库重新构建和校验。迁移、回退、再次升级和拒绝数据丢失有独立合成测试。
